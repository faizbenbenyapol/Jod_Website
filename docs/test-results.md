## 2. ทดสอบหน้าจอด้วยมือ (เบราว์เซอร์ จอมือถือ 375px)

| สิ่งที่ลอง | ผลที่เห็น |
|---|---|
| กดบันทึกโดยไม่ใส่ยอดขาย | ข้อความแดงใต้ช่อง + เคอร์เซอร์ไปที่ช่องนั้น |
| ใส่ค่าแก๊ส -5 | "จำนวนเงินติดลบไม่ได้" ใต้แถวนั้น |
| จดวันเดิมซ้ำ | ป๊อปอัปเทียบ "ที่จดไว้แล้ว" กับ "ที่เพิ่งกรอก" ให้เลือกบวกเพิ่ม/แทนที่/ยกเลิก |
| เลือก "อื่นๆ" ไม่พิมพ์ว่าค่าอะไร | บันทึกไม่ได้ "บอกหน่อยว่าเป็นค่าอะไร" → พิมพ์ "ค่าซ่อมร่ม" แล้วผ่าน |
| ลืมจด 2 วัน (แผง 08) | แถบเตือนพร้อมปุ่ม "จดของเมื่อวาน" → จดแล้วแถบเหลือ "ยังไม่ได้จด 1 วัน" |
| ดูย้อนหลัง ต.ค. / ก.ย. | ต.ค. "จดแล้ว 13 จาก 15 วันที่ผ่านมา" เฉลี่ยกำไร 909 / ก.ย. "25 จาก 30 วัน" เฉลี่ย 840 (ตรงกับคิดมือ: 21,000 ÷ 25 = 840) |
| หน้าทีม กดแท็บ / ค้นหา "ผักสด" | แท็บแสดงเฉพาะกลุ่ม (โทร 7 / เตือน 18), ค้นหาได้ 6 แผงจากทุกกลุ่ม |
| รีเซ็ตข้อมูลเดโม | ป๊อปอัปของแอป โฟกัสที่ "ยกเลิก" ก่อน → ยืนยันแล้วข้อมูลกลับชุดแรก + ข้อความ "รีเซ็ตเป็นข้อมูลเดโมชุดแรกแล้ว" |
| จอ iPad 768px / โน้ตบุ๊ก 1280px | เมนูย้ายขึ้นด้านบน, โน้ตบุ๊กแบ่ง 2 คอลัมน์, ไม่มีการเลื่อนแนวนอนทุกขนาด (วัดตำแหน่งด้วยสคริปต์ ไม่ได้ดูด้วยตาทั้งจอ) |

## 4. ข้อจำกัดของการทดสอบ (สิ่งที่ยังไม่ได้ตรวจ)
- **ยังไม่ได้ทดสอบกับแม่ค้าจริง** — ความง่ายในการใช้เป็นการประเมินของผู้พัฒนาเท่านั้น
- ไม่มีเทสต์อัตโนมัติฝั่งหน้าเว็บ (ปุ่ม กราฟ ปฏิทิน) — ตรวจด้วยมือในเบราว์เซอร์ตามตารางข้อ 2
- ทดสอบบน Chromium (เบราว์เซอร์ในแอป) อย่างเดียว ยังไม่ได้ลอง Safari บน iPhone/iPad จริง
- ไม่ได้ทดสอบหลายคนบันทึกพร้อมกัน (ระบบเก็บข้อมูลเป็นไฟล์เดียว เหมาะกับต้นแบบเท่านั้น)
